# Fair play policy

ProphyLens is for completed-game study.

The project will not ship:

- live-board overlays;
- browser extensions that suggest moves during active games;
- automatic detection of an active board followed by engine output;
- hidden assistance modes;
- cheat accusations based on engine correlation.

Provider imports must request finished games only. The interface should show “For post-game study only” near import and analysis actions. Contributions designed for live assistance will be rejected even if technically interesting.
